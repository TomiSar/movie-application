# Full Stack Development with Java Spring Boot, React, and MongoDB

## Spring boot initializer
* https://start.spring.io/

## Endpoints
* All Movies:  localhost:8080/api/v1/movies
* Movie (imdbId):  localhost:8080/api/v1/movies/{imdbId}
* All Reviews: localhost:8080/api/v1/reviews
* Review (id):  localhost:8080/api/v1/movies/{Id}
